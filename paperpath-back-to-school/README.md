# Back to school — Paperpath

A Back to school campaign for a fictional stationery sender, created with frontend-design and copywriting.

[Local preview](preview-local.html) · [Desktop](screenshot.png) · [Mobile](screenshot-mobile.png) · [Copy notes](COPY.md)

## Design

Product catalogue: an editorial opening and a native paired selection with useful descriptions. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. A generous visual pause keeps the offer details clear of the artwork as the mobile crop changes. Background art is decorative; essential information remains in live and plain text.

Palette: surface #f0ddbd, foreground #533f38, secondary #71574a, action #a9533b with #fff6e5 text. Solid fallback text and action contrast was checked at >=4.6:1. Palatino Linotype,Book Antiqua,Palatino,serif for display; Trebuchet MS,Lucida Sans Unicode,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
