# Own the project

Borrow is a fictional neighbourhood tool lending library. A membership promotion structured as a tool checkout slip, with a punchy photograph arriving before the main headline. Warm canary yellow and near-black, uncompromising monospace labels, heavy sans-serif declaration, dashed lending receipt and a large annual membership amount. Its organizing idea is borrowing the kit while owning the achievement.

Visual palette: yellow #f6d94f, ink #20251f, pale receipt #faf7e9. A photographic still life of a used drill, hammer and clamps on dark green worktop, tools carefully arranged with real wear. Main copy: OWN THE PROJECT. BORROW THE TOOLS. Use a literal inventory of useful jobs/kit, then a checkout-like membership close. £18 per year is a clearly fictional sample offer. The photograph contains no lettering; all inventory and price information stays native.

Mobile: image first, then short broken headline, then receipt rows; retain strong dark/yellow changes of field, no small illegible catalogue grid. Keep the membership action obvious. Campaign-specific inventory replaces generic benefits cards.

## Native translation

The concept’s checkout structure is preserved through editable dashed borders, native inventory rows and a bold membership close. The little tool thumbnails and illustrated receipt edges in the design study are omitted; one original tools photograph carries the material detail. Practical copy stays live. The title is sized for a normal Arial fallback at mobile widths.
