# New Year — Miles Ahead

A New Year campaign for a fictional community running club sender, created with frontend-design and copywriting.

## Design

Programme: a clear invitation and three sequential stages in native label/content columns. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. Background art is decorative; essential information remains in live and plain text.

Palette: surface #183d4a, foreground #fff4dd, secondary #d9e6e6, action #e8c36b with #183d4a text. Solid fallback text and action contrast was checked at >=4.6:1. Trebuchet MS,Lucida Sans Unicode,sans-serif for display; Tahoma,Verdana,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
