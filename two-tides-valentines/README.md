# Valentine’s Day — Two Tides

A Valentine’s Day campaign for a fictional spa retreat sender, created with frontend-design and copywriting.

## Design

Ritual card: calm typography and centered steps that connect the offer to an easy, concrete experience. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. Background art is decorative; essential information remains in live and plain text.

Palette: surface #e7e3db, foreground #344e50, secondary #4f6666, action #48767a with #fff5e3 text. Solid fallback text and action contrast was checked at >=4.6:1. Optima,Candara,Palatino Linotype,serif for display; Verdana,Geneva,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
