# A whole world at ankle height

An illustrated coastal field-class invitation composed as a naturalist notebook, with an original watercolour tidepool plate, live numbered observations and a practical booking page.

Created with the email-design skill: original visual direction and [design study](design/concept.png), then native Weavour implementation. [Design intent](design/intent.md) records the campaign idea, intended copy, mobile reading order and translation decisions.

## Native design

The generated study becomes a native field notebook with a large illustrated plate. Small handwritten labels and supplementary drawings from the concept are omitted so no factual identification claims or essential lettering are baked into artwork. Native numbered observation rows replace the study’s side-by-side essay columns for readable mobile use. The large heading uses two live lines.

All essential text, headings, prices, campaign details, buttons and structure are native editable Weavour blocks. There is no monolithic HTML block and no campaign lettering in the production image. Typography uses local system font stacks with fallbacks; no web font dependency.
