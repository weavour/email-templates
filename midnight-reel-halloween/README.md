# Halloween — Midnight Reel

A Halloween campaign for a fictional independent cinema sender, created with frontend-design and copywriting.

## Design

Admission ticket: a split masthead, a bold invitation, practical admission details and programme rows. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. Background art is decorative; essential information remains in live and plain text.

Palette: surface #191b24, foreground #f6f0dd, secondary #d3d8df, action #f3a35c with #191b24 text. Solid fallback text and action contrast was checked at >=4.6:1. Avenir Next,Avenir,Trebuchet MS,sans-serif for display; Verdana,Geneva,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
