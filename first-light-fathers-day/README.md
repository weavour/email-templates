# Father’s Day — First Light Roasters

A Father’s Day campaign for a fictional specialty coffee sender, created with frontend-design and copywriting.

## Design

Product catalogue: an editorial opening and a native paired selection with useful descriptions. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. Background art is decorative; essential information remains in live and plain text.

Palette: surface #352a23, foreground #fff0da, secondary #e6d8c4, action #dca66a with #352a23 text. Solid fallback text and action contrast was checked at >=4.6:1. Avenir Next,Avenir,Trebuchet MS,sans-serif for display; Verdana,Geneva,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
