# Seasonal collection validation

Scope: all 40 new campaign documents across 13 occasions and 11 industries, with 40 original selected background artworks.

## Export and local previews

- All 40 passed the actual Weavour native import, unchanged reopening and HTML export checks, including authored text, action destinations and background attributes.
- All 40 have desktop 800px and mobile 375px screenshots with loaded backgrounds, no horizontal overflow and keyboard access to the first link.
- All 40 offline HTML previews load their relative artwork, retain a readable solid background and unsubscribe token, and keep both campaign buttons on one destination.
- Final asset content hashes and embedded prompt histories are present. Each template exports one native background attribute and one Outlook VML fallback.
- The existing two-tag taxonomy and D1 statement-size limits were checked.

## Design and copy review

Four desktop and four mobile contact sheets cover all 80 rendered views. Selected full-size captures were inspected where artwork approached live copy. The final artwork and spacing protect text fields; the florist and garden campaigns use separate quiet offer placements. Thirteen composition types, distinct sender palettes, display/body pairings and forty campaign-specific narratives provide variety beyond color changes. Authoring defaults for newly inserted text and buttons match each sender; changing those defaults preserved the existing exports.

Every campaign has a selected subject, preheader, headline, offer, practical detail, primary CTA and closing argument. COPY.md records the audience assumptions, rationale and unused headline/CTA alternatives. All commercial and programme details are illustrative; no real testimonials, performance figures or guaranteed donation allocations are invented.

## Catalog checks and release status

The source catalog now contains 154 templates. All five catalog tests pass, including background inventory validation and idempotent migration-backed imports that preserve independent copies and revision history. Reviewable SQL was generated locally. The committed 101-template provisioning snapshot remains unchanged and verifies successfully.

These are source, browser and export checks, not certification across mailbox clients. New assets have not been published, no hosted tenant libraries were imported, and no application deployment or email send was performed.
