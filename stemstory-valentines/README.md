# Valentine’s Day — Stemstory

A Valentine’s Day campaign for a fictional florist sender, created with frontend-design and copywriting.

[Local preview](preview-local.html) · [Desktop](screenshot.png) · [Mobile](screenshot-mobile.png) · [Copy notes](COPY.md)

## Design

Editorial lookbook: a quiet centered masthead, high-contrast display type, an image-led pause and paired collection stories. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. A generous visual pause keeps the offer details clear of the artwork as the mobile crop changes. Background art is decorative; essential information remains in live and plain text.

Palette: surface #f2d9d2, foreground #66333f, secondary #7a4a54, action #9b364c with #fff4e8 text. Solid fallback text and action contrast was checked at >=4.6:1. Didot,Bodoni MT,Times New Roman,serif for display; Verdana,Geneva,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
