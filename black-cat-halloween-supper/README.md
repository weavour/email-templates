# Supper After Dark

A Halloween campaign for a fictional restaurant sender, created with frontend-design and copywriting.

[Local preview](preview-local.html) · [Desktop](screenshot.png) · [Mobile](screenshot-mobile.png) · [Copy notes](COPY.md)

## Design

Printed menu: centered invitation, seasonal offer, individual course or service descriptions and a reservation close. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. A generous visual pause keeps the offer details clear of the artwork as the mobile crop changes. Background art is decorative; essential information remains in live and plain text.

Palette: surface #231c2d, foreground #fff0d8, secondary #e1d4df, action #e6a65f with #231c2d text. Solid fallback text and action contrast was checked at >=4.6:1. Baskerville,Times New Roman,serif for display; Trebuchet MS,Lucida Sans Unicode,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
