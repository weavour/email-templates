## Design

Personal letter: greeting and editorial invitation, flowing paragraphs, a signed close and a clear action. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. Background art is decorative; essential information remains in live and plain text.

Palette: surface #e4e9db, foreground #3e5142, secondary #566851, action #4b745a with #fff5dc text. Solid fallback text and action contrast was checked at >=4.6:1. Optima,Candara,Palatino Linotype,serif for display; Verdana,Geneva,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
