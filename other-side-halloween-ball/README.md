## Visual direction

A surreal practical paper-theatre world: a carved pumpkin ringmaster, floating ivory masks, dark ribbons and a chartreuse crescent. Nearly black #10120f supports acid lime #d8ff42 poster lettering, ember #ff783f actions and warm ivory #f3ecd9 copy. Futura / Avenir Next / Trebuchet MS carries the live display type; Verdana / Geneva keeps the programme readable. This sender identity is distinct from Weavour’s website branding and editor chrome.

One continuous original background covers a native outer section. Transparent nested layouts hold the opening, programme, admission details and closing action. The illustration has its own generous stage between the live introduction and the programme. No panel joins, monolithic HTML blocks or rasterized campaign text are used. Native columns give the programme a clear time/content rhythm; the ticket details keep date, age and price explicit. The solid near-black fallback preserves readable content when decorative imagery is unavailable. Static artwork keeps the design independent of animation support.
