# Breakfast gets brighter

Sunroom is a fictional small-batch preserve maker. Create a sunlit grocery order slip rather than a lifestyle newsletter: tomato-red small masthead, warm yellow stock, one bold citrus-and-jar still life, a ruled tasting ledger with flavour/texture/pairing, a live large £8 price and tear-off-style order close. Headline: Breakfast gets brighter. Product: Pink grapefruit marmalade, 220g, £8. Specific copy about bittersweet peel and thick-cut toast; no inflated health claims or invented sourcing facts. Contrasting native type families: friendly Georgia headline, practical Arial body and Courier ledger labels. Mobile keeps practical details readable and the price obvious.

Design first: create a visual study before inspecting the native block schema. Keep study images separate from production assets.

## Implementation and visual review

The visual study’s decorative sun mark is omitted, keeping the sender name live editable. The tasting table and price remain native columns and sections. The order-close dashed rule is a native border. Desktop and mobile renders were compared with the study.
