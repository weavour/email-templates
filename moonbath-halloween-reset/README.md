# Halloween — Moonbath

A Halloween campaign for a fictional bath and body care sender, created with frontend-design and copywriting.

## Design

Ritual card: calm typography and centered steps that connect the offer to an easy, concrete experience. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. A generous visual pause keeps the offer details clear of the artwork as the mobile crop changes. Background art is decorative; essential information remains in live and plain text.

Palette: surface #30273c, foreground #f7eada, secondary #e3d6df, action #e5b895 with #30273c text. Solid fallback text and action contrast was checked at >=4.6:1. Baskerville,Palatino Linotype,Palatino,serif for display; Verdana,Geneva,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
