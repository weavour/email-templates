# Review of the latest 80 templates

Reviewed on 2026-10-19. The original 21 templates are outside this revision's editorial scope. Template IDs and import identities are preserved.

## Findings addressed

- Artwork had been assigned in rotation, producing unrelated combinations such as a bicycle-service email with an espresso photo. Active images now match the campaign subject. Text-led campaigns use typography instead of unrelated decoration.
- Every template reused the same three filler sections. Each now has three campaign-specific sections: service details, menus, programmes, product information, practical checklists or editorial notes.
- Some layout variants inherited unrelated appeals or hardcoded headings. The revised documents contain only their own campaign copy.
- Repeated introductions added height and occasionally promised content that was absent. Each email now has one introduction that agrees with its actual contents.
- Repeated palettes and cramped column structures weakened the brands. The revision uses palette and typography choices suited to each niche, intentional full-width passages and paired native columns for shorter content.
- Image provenance sometimes described reuse inaccurately. Each template README now records its active assets, actual generation prompts, reuse sources and specific alternative text.

## Collection

The revised 80 include 47 image-led designs and 33 intentionally text-led designs. Six campaigns use a second relevant image. New photographs were generated with OpenAI's built-in image generation tool; existing generated artwork is reused where it fits the subject. Historical files and published URLs remain intact.

## Creative composition revision

The latest 80 now have independent art directions rather than a shared headline/image/three-section scaffold. [design-variety.json](design-variety.json) records the concept and heading typography for each template. Examples include work orders, cinema tickets, record sleeves, ruled ledgers, theatrical bills, postcards, newspaper editions, field guides, reference sheets and type specimens. These change native block arrangement, hierarchy, image placement, whitespace, columns and the order of the call to action. Email-safe font families provide serif, condensed display, humanist sans and monospace voices without requiring remote fonts.

## Validation and limitations

The editor rendering workflow checks native schema import, lossless reopen, exported copy, image sources and alternative text, button destinations, keyboard access and horizontal overflow. Desktop and mobile screenshots use 800px and 375px viewports. Palette checks cover supporting text on both paper and inset backgrounds, plus button labels; the minimum checked contrast ratio is 4.95:1.

All senders, offers, dates, programme details, metrics and software capabilities are fictional examples. Replace them with verified campaign details and configure links, sender identification and unsubscribe substitution before sending. Browser rendering is not a substitute for testing in the email clients used by a sender's audience.
