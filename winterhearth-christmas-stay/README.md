# Christmas — Winterhearth

A Christmas campaign for a fictional alpine boutique hotel sender, created with frontend-design and copywriting.

## Design

Travel postcard: generous editorial opening, a visual pause, then a short itinerary and booking close. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. Background art is decorative; essential information remains in live and plain text.

Palette: surface #182e2d, foreground #faf3df, secondary #dce5d8, action #d9aa6e with #182e2d text. Solid fallback text and action contrast was checked at >=4.6:1. Baskerville,Palatino Linotype,Palatino,serif for display; Verdana,Geneva,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
