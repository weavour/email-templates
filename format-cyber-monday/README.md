## Design

Service checklist: a concrete offer, native list of included steps and explicit scope before the action. Native blocks change the actual reading order and layout; this collection does not rely on palette swaps alone. One original continuous background sits on an outer section, with transparent nested layouts so content reflow creates no background joins. All headlines, descriptions, offers and calls to action remain editable. Background art is decorative; essential information remains in live and plain text.

Palette: surface #ebebe5, foreground #333e43, secondary #556168, action #ad442e with #fff7e9 text. Solid fallback text and action contrast was checked at >=4.6:1. Futura,Avenir Next,Trebuchet MS,sans-serif for display; Trebuchet MS,Lucida Sans Unicode,sans-serif for body copy. Local/email-safe fallbacks are explicit; no external web-font dependency. Fictional sender styling is independent of Weavour’s editor chrome and website branding.
